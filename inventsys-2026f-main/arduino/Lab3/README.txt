=== WHAT IT DOES ===
The code is paired with a small grave / burial plot interface. The gravestone is wrapped in aluminum foil and serves as the capactive touch
input. Buried in the tomb is the haptic motor, which vibrates at a speed relative to how near / how much you are touching the gravestone.
The more you touch the grave, the angrier the haptic motor spirit gets. 

This code was built off of the VibrationMotorCapactiveButton.ino and adjoining .h example files provided to the class. 

=== HOW TO RUN IT === 
Simply upload the code. The circuit is identical to the VibrationMotorBasic schematic, with the addition of one singular jumper wire
on touch sensor 4 (18) running into the gravestone. 

=== AI USE ===
I used no AI used in this lab.
